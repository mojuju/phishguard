# Dataset

The dataset is not included in this repository.

1. Download a phishing email dataset from Kaggle, for example **"Phishing Email Detection"**
   (columns `Email Text` and `Email Type`).
2. Save the CSV here as `data/emails.csv`.

Other datasets work too: `phishguard/data.py` detects the text and label columns automatically.

Tip for Windows: if hidden file extensions are on, make sure the file isn't named `emails.csv.csv`.
